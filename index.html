Eure WG, gut abgesprochen.

Putzplan, Urlaub, Vertretungen und ein kleiner Flurfunk für Neuigkeiten. Kostenlos, ohne Konto und Ende-zu-Ende verschlüsselt.

WG gründen Mit Code beitreten

Läuft im Browser auf Handy und Laptop. Zum Startbildschirm hinzufügen, dann fühlt es sich an wie eine App.

Putzplan, der sich weiterdreht

Treppe, Müll, Küche: Jede Woche ist jemand anderes dran. Wer im Urlaub ist, wird übersprungen.

Schaffe ich nicht

Bitte um Vertretung oder tausch die Woche mit jemandem. Die anderen sehen es sofort.

Erledigt und Danke

Kurz abhaken, die WG sieht es im Flurfunk und kann sich bedanken. Wer mag, bewertet.

Fair verteilt

Die Statistik zeigt, wer wie viel gemacht hat. Ohne Punkte-Drama, einfach zum Nachschauen.

So geht's

  1. WG gründen. Name der WG und dein Name, fertig. Kein Konto, keine E-Mail.
  2. Code teilen. Du bekommst einen Einladungscode (auch als QR-Code). Zeig ihn deinen Mitbewohnern.
  3. Loslegen. Alle sehen denselben Plan. Änderungen kommen bei den anderen an, auch wenn ihr Handy gerade aus ist.

Datenschutz

Wir können eure Daten nicht lesen.

Eure WG-Daten werden auf euren Geräten verschlüsselt, bevor sie zum Abgleich auf unseren Server gehen. Der Schlüssel steckt im Einladungscode, und den bekommt der Server nie. Er sieht nur verschlüsselte Pakete und wann sie ankommen.

  • Keine Konten, keine E-Mail-Adressen, keine Telefonnummern
  • Keine Werbung, kein Tracking, keine Cookies
  • Server in Deutschland
  • Unbenutzte WGs löschen sich nach 180 Tagen vom Server

Wichtig: Wer den Code kennt, gehört zur WG. Teilt ihn nur mit Leuten, die bei euch wohnen.

Fragen

Was kostet Flurfunk?

Nichts. Flurfunk ist ein kleines Projekt ohne Werbung.

Was passiert, wenn ich mein Handy verliere?

Die Daten eurer WG liegen verschlüsselt auf dem Server und auf den Geräten der anderen. Lass dir den Code von einem Mitbewohner zeigen und tritt auf dem neuen Handy wieder bei.

Jemand zieht aus. Und jetzt?

Die Person verlässt die WG in der App. Den Einladungscode kennt sie aber weiterhin. Wenn euch das stört, gründet eine neue WG mit neuem Code. Einen Code-Wechsel per Knopfdruck gibt es noch nicht.

Funktioniert es auch offline?

Ja. Ohne Netz arbeitet die App mit dem, was auf dem Gerät liegt. Sobald wieder Netz da ist, wird abgeglichen.
